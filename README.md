# 補助曲線つき等高線と舗装区域ジェネレータ

[Webアプリを開く](https://tjmsy.github.io/omapsource_export/)

産総研シームレス標高タイル（統合DEM）と国土地理院ベクトルタイルをもとに、補助曲線つき等高線と舗装区域をクライアントサイドの演算で生成するWebアプリです。  
通常の等高線に加え、標高データから計算した傾斜や起伏の特徴に基づく補助曲線も表示します。  
生成した各データと元データの道路縁を、GeoJSONファイルとして保存できます。

## 主な機能

- 表示範囲の補助曲線つき等高線と舗装区域のリアルタイム生成
- 等高線の間隔を 1m / 2m / 2.5m / 5m から選択可能
- 以下のレイヤを個別に GeoJSON として保存可能
  - 等高線（主曲線）
  - 等高線（計曲線）
  - 等高線（補助曲線）
  - 舗装区域
  - 道路縁

## データの保存

1. 地図ツールパネルの「レイヤごとに保存」から保存したいレイヤを選択します。
2. ダウンロードされるファイルは GeoJSON の FeatureCollection です。

> [!NOTE]
> 保存対象は、現在の地図表示に読み込まれているデータです。地図を移動・拡大縮小して対象範囲を表示し、データの読み込みが完了してから保存してください。等高線は、その時点での間隔設定で生成されます。

## データ出典

- 等高線・補助曲線: [産総研シームレス標高タイル（統合DEM）](https://tiles.gsj.jp/tiles/elev2/index.html#h_mixed)
- 舗装区域・道路縁: [国土地理院 最適化ベクトルタイル](https://github.com/gsi-cyberjapan/optimal_bvmap)
- 背景地図: [OpenFreeMap](https://openfreemap.org/)

地図データの利用条件や帰属表示については、各データ提供元の案内をご確認ください。
