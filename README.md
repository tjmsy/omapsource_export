# 舗装区域・等高線生成

国土地理院ベクトルタイルと産総研シームレスタイルから舗装区域と等高線をクライアントサイド生成します。

生成したベクトルデータを GeoJSON ファイルで保存できます。

## 主な機能

- 表示範囲の舗装区域と等高線を生成
- 等高線の間隔を 1 m、2 m、2.5 m、5 m から選択
- 次のレイヤを個別に GeoJSON で保存
  - 等高線（主曲線）
  - 等高線（計曲線）
  - 等高線（補助曲線）
  - 舗装区域
  - 道路縁

## データの保存

地図ツールパネルの「レイヤごとに保存」から保存するレイヤを選びます。ダウンロードされるファイルは GeoJSON の FeatureCollection です。

保存対象は、現在の地図表示に読み込まれているデータです。地図を移動・拡大縮小して対象範囲を表示し、データの読み込みが終わってから保存してください。等高線は表示中の間隔設定で生成されます。

## データ出典

- 等高線・補助曲線: [産総研シームレス標高タイル（統合DEM）](https://tiles.gsj.jp/tiles/elev2/index.html#h_mixed)
- 舗装区域・道路縁: [国土地理院 最適化ベクトルタイル](https://github.com/gsi-cyberjapan/optimal_bvmap)
- 背景地図: [OpenFreeMap Positron](https://tiles.openfreemap.org/styles/positron)

地図データの利用条件や帰属表示については、各データ提供元の案内を確認してください。
